# Premium Engineering Portfolio

This is a standalone version of your Electrical & Automation Engineering portfolio.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (usually comes with Node.js)

### Installation
1. Extract the provided archive.
2. Open your terminal/command prompt in the project folder.
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the development server:
```bash
npm run dev
```
The website will be available at `http://localhost:3000`.

### Production Build
To create a production-ready version:
```bash
npm run build
```
The static files will be generated in the `dist/` folder, which you can host on GitHub Pages, Netlify, Vercel, or any other hosting provider.

## Project Structure
- `src/App.tsx`: Main application code and data.
- `src/assets/`: Image assets and PDFs.
- `public/`: Publicly accessible static files.
- `tailwind.config.js`: CSS configuration.
- `vite.config.ts`: Build tool configuration.
